# 🎥 NexoMeet

NexoMeet is a modern video conferencing platform built with **Next.js**, **WebRTC**, and **WebSockets**. It enables users to create and join meetings, schedule upcoming meetings, maintain meeting notes, and leverage AI to generate  notes.

---

##  Live Demo

**Try NexoMeet:**  
https://nexomeet-a99g.onrender.com/

##  Features

###  Meetings
- Create instant meetings
- Join meetings using an invitation link
- Schedule meetings for later
- Personal meeting room
- Real-time video and audio communication
- Camera and microphone controls

###  Meeting Takeaways
- Create and save meeting notes
- View all saved meeting takeaways
- Organize notes by meeting
- Edit notes anytime after the meeting


###  Meeting Management
- Upcoming meetings
- Previous meeting history
- Scheduled meeting dashboard

### 🔐 Authentication
- Secure user authentication with Clerk
- Protected dashboard and meeting rooms
